# Каталог плагинов OpenCode V2

Короткий каталог плагинов для **OpenCode V2**. Каждый плагин живёт в отдельном
репозитории; здесь собраны ссылки, версии и краткое описание того, что он
делает.

Актуально на **8 ноября 2026**. Большинство плагинов проверено на OpenCode
**2.2.5**; GoCost — на **2.2.6**, LocalAI — на 2.0.24 (см. его README).

## Коротко о каждом

### CompactionSlider

Управляет порогом автоматического сжатия контекста для каждой модели отдельно.
Проценты хранятся в плагине и применяются через `model.transform`, поэтому
`opencode.json` не переписывается. Ниже 95 % слайдер шагает по 5 %, с 95 % —
по 1 %, чтобы верхнюю границу можно было выставить точно.

### DeepSeekPeak

Показывает, действует ли сейчас у DeepSeek зона Peak или Non-Peak. Метка
появляется только при выбранной модели DeepSeek, обновляется раз в 30 секунд и
по клику открывает диалог с текущим временем, следующей сменой и расписанием.
Календарь праздников Китая на 2026 год уже внутри; его можно заменить через
`options.holidays`.

### GoCost

OpenCode Go присылает `cost = 0`, поэтому встроенный футер скрывает стоимость.
Плагин подменяет общий `context.data.session.cost` и возвращает оценку по
токенам сессии и ценам каталога моделей. Сумма появляется в штатном месте — там
же, где её рисует встроенный футер, — и форматируется его же
`Intl.NumberFormat`. Это оценка по прайс-листу, а не счёт провайдера.

Там же, в правой панели, показываются лимиты OpenCode Go: 5-часовое окно,
неделя и месяц. Для каждого — процент, тематическая полоса и обратный отсчёт до
сброса; данные берутся из того же кэша, что у встроенного диалога Usage.

### LocalAI

Плагин discovery для локальных моделей: читает `/v1/models` у
OpenAI-совместимого сервера (llama.cpp / llama-swap), определяет контекст и
возможности и публикует модели в OpenCode под именами `local-*`. Работает с
локальными моделями без ручной правки `providers` в `opencode.json`.

### MCPClassify

Группирует MCP-серверы в сайдбаре по классам и делает каждый уровень
сворачиваемым. Встроенная секция MCP отключается директивой
`"plugins": ["-opencode.sidebar.mcp"]` в `cli.json`. Клик по серверу
подключает или отключает его, состояние свёртки сохраняется между запусками.

### ModelsDisabler

Оставляет в списке моделей Zen/Go только бесплатные и явно разрешённые.
Определяет бесплатность по суффиксу `-free` или нулевой цене и выставляет
`disabled: true` для платных моделей через `model.transform`. Полезен, чтобы не
тратить платные лимиты случайно.

### ProxyRouter

Создаёт локальный HTTP-relay и подменяет `baseURL` выбранных моделей, чтобы
запросы шли через SOCKS5 или HTTP-прокси. Нужен для моделей, недоступных
напрямую из региона. Поддерживает allowlist моделей, health-check и команду
`/proxy status`.

## Установка

Каждый плагин устанавливается отдельно — подробности в README его
репозитория. Общая схема для большинства:

1. Скопировать каталог `plugin/` в
   `~/.config/opencode/plugins/<имя>/` (Windows:
   `%USERPROFILE%\.config\opencode\plugins\<имя>\`).
2. Перезапустить сервис: `opencode service restart`, затем открыть TUI заново.
3. Для плагинов, которым нужны `options` (например, `ProxyRouter`), добавить
   объектную запись в `cli.json` или `opencode.json` — см. README плагина.

## Обновления каталога

Версии в таблице соответствуют `plugin/package.json` в каждом репозитории на
дату, указанную выше. При обновлении плагина обновляйте и эту таблицу.
